# CardSync — pages publiques

Assistance et politique de confidentialité de l'app iPhone **CardSync**, publiées via
GitHub Pages. Ce dépôt ne contient que ces pages : le code de l'app est ailleurs et reste
privé.

| Page | Adresse |
|---|---|
| Assistance (FR) | `/` |
| Confidentialité (FR) | `/confidentialite.html` |
| Support (EN) | `/en/` |
| Privacy (EN) | `/en/privacy.html` |

Les URL d'assistance et de confidentialité sont des champs obligatoires d'App Store
Connect, et le champ d'assistance est renseigné **par langue**.
